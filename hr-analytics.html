People analytics / Power BI

HR Analytics

An interactive Power BI dashboard exploring attrition patterns across 1,470 employee records in the fictional IBM HR Analytics dataset.

View on GitHub ↗Explore live report ↗
Project typeIndependent portfolio project
AudienceHR and workforce planning
ToolsPower BI · Power Query · DAX

The question

Which employee groups show higher attrition, and what patterns deserve attention?

The report connects workforce demographics with overtime, compensation, satisfaction, and tenure. It supports exploring patterns across employee groups using cross-filtering and clear report navigation.

How I built it

  • Cleaned the data and created age, salary, and education groupings with Power Query.
  • Built DAX measures for attrition rates, segment comparisons, and dynamic narrative text.
  • Designed an attrition overview and a separate employee deep dive.
  • Used conditional formatting and cross-filtering to support further exploration.

The outcome

The dashboard helps compare attrition across departments and job roles, then examine how overtime, income, satisfaction, and tenure relate to the observed patterns.

Financial analytics / Power BI

Saudi Banking Credit

An interactive Power BI report connecting economic sector lending, residential mortgages, and consumer credit in one view.

View on GitHub ↗Explore live report ↗
Project typeIndependent portfolio project
AudienceFinancial and economic analysis
ToolsPower BI · Power Query · DAX

The question

How has bank lending changed across sectors, housing, and consumer credit?

Different lending categories cover different periods. The report brings them together while keeping the available date ranges clear, including the long-run consumer credit series from 1998 to 2025.

How I built it

  • Prepared and reshaped SAMA data with Power Query.
  • Designed a star-schema model with a shared date dimension and three fact tables.
  • Built DAX measures for growth, time comparisons, and dynamic report insights.
  • Separated total consumer lending history from the detailed categories available from 2016.

The outcome

Four report pages provide a route from the overall story into sector lending, mortgages, and consumer credit. Dynamic formatting makes financial values easier to read as filters change.

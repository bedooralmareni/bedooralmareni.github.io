LEGO Theme Graveyard

A guided Power BI story about the lifespan of LEGO themes, designed for a curious audience with no technical background required.

View on GitHub ↗Explore live report ↗
Project typeIndependent portfolio project
AudienceA general, curious audience
ToolsPower BI · Power Query · DAX

The question

Why did so many LEGO themes disappear while a few endured for decades?

The report explores 149 top-level themes through a graveyard-inspired narrative. An entrance page leads into discontinued themes, surviving themes, and a closing perspective on their legacy.

How I built it

  • Built the story using the contest data model shared by Stephanie Bruno.
  • Counted themes at the top level and focused on sets with at least one part.
  • Defined active themes as those with a set released in 2023 or later.
  • Used a guided page sequence, direct chart subtitles, and consistent visual storytelling.

The outcome

The analysis shows a typical theme lifespan of five years. The report compares short-lived themes with enduring ones and makes the classification rules visible so readers can interpret the findings.
